# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting Vulnerabilities

Security is a core feature of SkillKit. If you discover a security vulnerability within SkillKit or its security scanning engine, please do NOT open a public GitHub issue.

Instead, please send a report to the maintainers detailing:
- The nature of the vulnerability
- Step-by-step instructions or sample markdown payloads to reproduce the issue
- Affected components or platforms

We aim to acknowledge receipt of vulnerability reports within 48 hours and provide a fix or mitigation plan promptly.
